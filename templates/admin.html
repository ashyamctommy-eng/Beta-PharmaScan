Sign in

The admin password is the one set on the server as ADMIN_PASSWORD.

No admin password is configured

The panel stays closed until one is set. On the server:

cd ~/pharmascan
python -m core.auth hash          # prints a hash; copy it into .env
# then in .env:
#   ADMIN_PASSWORD_HASH=scrypt$...
#   SESSION_SECRET=<python -m core.auth secret>   (optional but recommended)
touch tmp/restart.txt

Or, for quick setup, set ADMIN_PASSWORD instead of the hash — it is hashed in memory at startup.
